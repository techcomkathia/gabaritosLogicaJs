# prática.js

Exercícios de lógica de programação com JavaScript, organizados por aula e por nível de dificuldade. Cada exercício tem um gabarito para você conferir depois de tentar.

### 👉 [Acesse o site: techcomkathia.github.io/gabaritosLogicaJs](https://techcomkathia.github.io/gabaritosLogicaJs/)

Funciona no computador e no celular, direto no navegador, sem instalar nada.

> **Aprender é fazer, testar e tentar de novo.**

## O que tem aqui

| Aula | Tema | Exercícios |
|---|---|---|
| 01 | Dados e cálculos | 18 |
| 02 | Decisões e condicionais (`if`, `else`, `switch`) | 33 |
| 03 | Repetição com `while` | 26 |
| 04 | Repetição com `for` | 37 |

Os exercícios estão em três níveis: **Fácil**, **Intermediário** e **Avançado**. Novas aulas podem ser adicionadas ao longo do módulo.

## Como usar

### 1. Escolha a aula

Clique em uma aula na **Trilha de aprendizado**, no menu lateral. No celular, o menu aparece no topo da página.

Cada aula tem seu próprio endereço, então você pode salvar nos favoritos a aula que está estudando. Por exemplo, a Aula 03 fica em [techcomkathia.github.io/gabaritosLogicaJs/#aula03](https://techcomkathia.github.io/gabaritosLogicaJs/#aula03).

### 2. Escolha a dificuldade

No campo **Dificuldade**, selecione:

- **Fácil**, **Intermediário** ou **Avançado** para praticar só aquele nível;
- **Aleatório** para misturar exercícios de todos os níveis.

A página mostra **6 exercícios por vez** e lembra o nível que você escolheu em cada aula.

### 3. Sorteie novos exercícios

Terminou a rodada? Clique em **Sortear questões** para receber outros 6 exercícios do mesmo nível.

### 4. Fixe uma rodada

Marque **Fixar estas questões** para guardar a rodada atual. Mesmo que você feche o navegador, os mesmos exercícios estarão lá quando voltar. Isso ajuda a terminar uma lista em dias diferentes. Enquanto a rodada está fixada, o botão de sorteio fica desativado; desmarque a opção para sortear de novo.

> A rodada fica salva só no navegador e no aparelho que você está usando.

### 5. Confira o gabarito

As respostas começam escondidas. Use:

- **Ver resposta**, em cada exercício, para abrir só aquele gabarito;
- **Mostrar todas as respostas**, acima da lista, para abrir ou fechar todos de uma vez.

### 6. Escolha o tema

O botão de sol/lua, no canto superior direito, alterna entre o tema escuro e o claro. Sua escolha fica salva.

## Código da questão: use para tirar dúvidas

Cada exercício mostra um código ao lado do número, por exemplo:

```
QUESTÃO 02   A04-Q03
```

- **QUESTÃO 02** é só a posição do exercício na rodada atual e muda a cada sorteio.
- **A04-Q03** é o código fixo do exercício: Aula 04, questão 03. Ele nunca muda.

Ao pedir ajuda para a professora ou para colegas, informe sempre o **código**. Assim todo mundo sabe exatamente de qual exercício você está falando, mesmo que cada pessoa tenha sorteado uma rodada diferente. Um clique no código seleciona o texto para você copiar.


## Dicas de estudo

- **Tente antes de abrir o gabarito.** Mesmo uma solução incompleta ensina mais do que ler a resposta pronta.
- **Comece pelo Fácil** e só avance quando conseguir resolver a rodada sem consultar o gabarito.
- **Compare, não copie.** Se sua solução é diferente do gabarito mas funciona, ótimo: em programação existem vários caminhos certos.
- **Teste com valores diferentes**, inclusive zero, números negativos e casos-limite. É assim que se encontram os erros.
- **Use o Aleatório para revisar** já que ele mistura todos os níveis.
- Os gabaritos consideram que você vai digitar dados válidos, como números onde se pede número. Porém sabemos que a conversão de strings para números pode produzir um NaN e alterar os resultados que consideram operações com tipos numéricos. Validar entradas é um bom desafio extra.
